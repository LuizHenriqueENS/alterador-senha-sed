# Alterador de Senhas SED

Projeto desenvolvido em 2022 com C# e Selenium para automatizar o processo de redefinição de senhas de alunos na plataforma Secretaria Escolar Digital (SED).

## Contexto

Este foi um dos meus primeiros projetos de automação, desenvolvido a partir de uma necessidade real do ambiente escolar.

Atualmente, o projeto encontra-se descontinuado e é mantido em sua versão original como registro do meu processo de aprendizagem e desenvolvimento na programação.

## Objetivo

O projeto surgiu da necessidade de agilizar um procedimento administrativo realizado manualmente na escola, que exigia acessar individualmente os registros dos alunos e redefinir suas senhas.

A automação utiliza o Selenium WebDriver para controlar o navegador, navegar pela plataforma, localizar os alunos e executar as etapas de redefinição de senha.

## Funcionalidades

- Acesso automatizado à plataforma SED.
- Seleção do tipo de ensino e da turma.
- Identificação dos alunos ativos.
- Recuperação dos dados necessários para redefinição.
- Alteração automatizada das senhas.
- Acompanhamento do progresso da execução.

## Tecnologias utilizadas

- C#
- .NET
- Selenium WebDriver
- ChromeDriver
- WebDriverManager
